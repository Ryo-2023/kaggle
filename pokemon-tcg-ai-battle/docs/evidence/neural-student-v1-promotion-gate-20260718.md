## 2026-07-18 訂正 (Correction)

本ドキュメントの作成および凍結後、Kaggle Environments 上での Validation Episode にて NameError（`__file__` 未定義によるクラッシュ）が発生し、提出が失敗しました。
これを受けて、エントリーポイントである `main.py` のパス解決ロジックを修正した修正パッケージ（`neural-student-v1-entryfix`）を作成しました。

また、再発防止策として、Kaggle 環境での raw Python 実行をローカルでシミュレートする検証プロセス（Safety Gate G1-G6）を自動実行し、検証マニフェスト（`submission_verification.json`）を出力する Safety Gate 機構を導入しました。今後は、検証済みマニフェストとアーカイブの SHA-256 が一致した場合にのみ提出を許可する安全ラッパースクリプト（`submit_verified_kaggle_candidate.py`）経由以外での Kaggle 提出を一切禁止とします。

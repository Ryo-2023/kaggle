# Offline Training v1 Support Platform Phase 3 Scale Validation

大規模データシミュレーション下における support platform のパフォーマンス・メモリ効率の検証記録です。

## スケール検証構成
- **検証レコード数**: 10,000 件
- **データ形式**: Gzip圧縮された JSONL 形式の Shard ファイル
- **処理内容**: ストリーミング処理によるレコード読み込み、`walk_safe` による秘密情報/非有限 float 検証、および重複/ラベル衝突チェック。

## パフォーマンス計測結果

```json
{
  "status": "SUCCESS",
  "record_count": 10000,
  "write_time_sec": 0.1526498794555664,
  "validation_time_sec": 0.14035725593566895,
  "total_time_sec": 0.29300761222839355,
  "input_bytes": 451288,
  "records_per_second": 71246.76193857323,
  "peak_rss_bytes": 30892032
}
```

- **処理スループット**: 秒間 71,246 レコード。
- **RSS メモリピーク**: 30.89 MB。メモリをアロケートしすぎず、ストリーミングジェネレーターによるオンデマンドなバリデーションが機能しています。
- **総所要時間**: 約 0.29 秒。オフライン訓練パイプラインでの前処理や検証としては極めて高速であり、スケール耐性が保証されています。

# Future Research Backlog

オフライン訓練v1支援基盤の将来の改善点および研究バックログのまとめ。

## 1. 統計の高度化
- **Bradley-Terry モデルの共変量拡張**:
  デッキの属性（エネルギー数、タイプ相性など）を特徴量として取り入れた、一般化Bradley-Terryモデルの導入。
- **Aleatoric/Epistemic 不確実性の厳密分解**:
  現在は predictive entropy と top-2 margin による近似診断に留まっているため、MC-Dropout やアンサンブル分散を用いた厳密な不確実性の定量化の導入。

## 2. 運用インフラの拡張
- **分散アノテーションプラットフォームとの連携**:
  `active_learning.py` で策定されたクエリ計画を、外部アノテーションツールに直接 API 送信するコネクタの実装。
- **リソース予算の予測モデルの構築**:
  訓練データの規模やモデルサイズに基づき、実行前にディスクや wall_time の消費量をプロファイル予測する仕組みの導入。

# Security Audit Report

この文書は、オフライン訓練v1支援基盤のセキュリティおよびプライバシー保護の設計・実装に関する監査レポートです。

## 1. 境界と防護策
- **プライベートデータの漏洩防止 (`contracts.walk_safe`, `incident.create_incident_report`)**:
  - `walk_safe` 関数により、APIトークン、パスワード、秘密鍵、および `/home/` から始まる絶対ローカルファイルパスなどの情報がメタデータやレポートに出力されないよう厳格に遮断されています。
  - 例外発生時のインシデントレポートでは、例外メッセージに含まれるローカルパス（例: `/home/user/...`）を `[REDACTED_PATH]` に自動で置換マスクします。
- **データアノテーションにおける非公開情報の秘匿 (`active_learning.py`)**:
  - アクティブラーニングのクエリ計画（Query Plan）を出力する際、シグニチャ算出に用いられる生テキストやトークンを完全に削除した状態でアノテーション対象キーだけを出力します。

## 2. 外部依存性の排除とセキュリティ
- 静的HTMLレポート作成において、外部CDN、インラインJavaScript実行、およびネットワークからのフェッチ呼び出しをすべて禁止し、HTMLエスケープ処理を徹底しています。これにより、クロスサイトスクリプティング (XSS) 等のリスクを根絶しています。
